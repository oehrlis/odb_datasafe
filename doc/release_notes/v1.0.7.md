# Release Notes - v1.0.7

**Release Date:** 2026-07-03
**Type:** Patch (bug fix - validate_inputs ordering in ds_target_reregister.sh)

## Summary

v1.0.7 fixes a parameter-validation ordering bug in `ds_target_reregister.sh`
where `require_oci_cli` was called before required CLI parameter checks.

## Changes

### Fixed: `validate_inputs()` — required params before `require_oci_cli`

`validate_inputs()` called `require_oci_cli` as its first action, before
checking whether `--target` and at least one update option were provided.

In CI environments without OCI CLI installed, this caused BATS tests for
missing-parameter errors to fail: the function aborted with
"Missing required commands: oci" before it could emit the expected
param-specific error message (`--target`, `--cluster`, etc.).

**Fix:** All required-parameter `die` checks now appear before
`require_oci_cli`, matching the project-wide `validate_inputs()` ordering
rule promoted in this release cycle.

## Upgrade Notes

No API or configuration changes. Drop-in replacement for v1.0.6.
